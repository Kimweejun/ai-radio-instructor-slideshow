# AI 무전 교관 (HyperFrames 슬라이드쇼 버전)

K-방산 2차 아이디어 내부 발표 자료를 HyperFrames 슬라이드쇼로 만든 버전입니다.

- `index.html`: 시작 화면, 인트로, 슬라이드쇼(조작 막대, 발표자 모드 `P`)
- `composition/index.html`: 슬라이드 장면 본체(HyperFrames 컴포지션)
- 부록은 본문의 작은 번호 배지를 누르면 열리고, `‹` 버튼으로 보던 장으로 돌아갑니다.
- `composition/assets/`의 사진은 AI 생성 이미지(OpenAI Codex)이며 실제 장면이 아닙니다.
- 로컬에서는 이 폴더에서 정적 서버를 띄워 엽니다: `python -m http.server 8000`
